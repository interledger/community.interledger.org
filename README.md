In 2026-11, the Interledger Foundation discontinued use of [Forem](https://github.com/forem/forem) forum.

This repository is for redirecting https://community.interledger.org URLs to their new location.

Edit the `_redirects` file using [Netlify’s _redirects file syntax](https://docs.netlify.com/manage/routing/redirects/overview/#syntax-for-the-_redirects-file).
